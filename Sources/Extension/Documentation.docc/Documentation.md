# ``Extension``

A modular collection of Swift, Foundation, Apple-framework, and macro utilities.

## Overview

Import `Extension` for the umbrella surface, or import an individual module such
as `FoundationExtension` when a client only needs one part of the package.

Use the cumulative migration guide for every major release between the version
currently used by a client and the latest version. API naming and compatibility
expectations are documented separately so new public surfaces remain consistent
across modules.
